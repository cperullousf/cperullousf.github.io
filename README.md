# Fieldnotes: Peru

A responsive, dependency-free sightseeing guide to Peru. Browse six destinations by region or search by name, save places for later, and explore a sample seven-day highlands route.

## View the site

Open `index.html` in a browser. No build step or package installation is required.

Photography and typefaces load from Unsplash and Google Fonts, so those assets require an internet connection. The layout and destination controls work without a JavaScript framework.
